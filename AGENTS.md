# Project memory

- Commit all outstanding project files iteratively, one file per commit.
- Keep each commit subject short: a phrase shorter than one sentence.
- Never add a `Co-authored-by` trailer or other coauthor attribution.
- The macOS menu bar app is built and relaunched with `make menu-bar`; the stable app path is `dist/KrillionBar.app`.
- Use the 36×36 transparent `MenuBarShrimp` asset for the status item. The full-size `Shrimp` image did not appear reliably in the menu bar. Restart old `KrillionBar` processes when testing a new build.
